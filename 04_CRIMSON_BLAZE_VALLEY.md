# 🔥 04. Lembah Api Merah (Crimson Blaze Valley) — Huangji-World

> **Status File**: Modul Lore Wilayah (Elemen Api & Vulkanik)
> **Versi**: 3.0 (Huangji Core Edition)
> **Spesialisasi Wilayah**: Alkimia (Alchemy), Pembuatan Pill, & Qi Api Destruktif

---

## 🏞️ I. Gambaran Umum Wilayah

Lembah Api Merah adalah rantai gunung berapi aktif dan danau lahar yang kaya akan Qi Elemen Api. Suhu udara ekstrem menjadikan wilayah ini tempat ideal bagi penyulingan pil alkimia, ekstraksi herba api, dan pertarungan kekuatan penuh.

* **Qi Density Modifier**: `+30% Efisiensi Alkimia & Damage Api`
* **Populasi Wilayah**: ± 32 Juta Jiwa
* **Kota Utama**: Kota Kawah Merah & Kota Magma Baru

---

## 📍 II. Lokasi Utama & Poin Penting (PoI)

### 1. Kota Kawah Merah (Red Crater City)
Kota panggung batu basal yang terapung di atas danau lahar raksasa.
* **Tungku Alkimia Agung**: Tempat persewaan tungku api vulkanik untuk meracik *Pill Alkimia* tingkat tinggi.

### 2. Gua Api Purba (Ancient Blaze Cave)
Sarang spirit beast tipe api dan tempat tumbuhnya *Bunga Ginseng Lava*.
* **Bahaya Alam Hardcore**: Udara beracun *Vulkanik Sulfur*. Menghirup udara gua tanpa *Pill Pendingin Tubuh* memberikan debuff **Burn Damage 10 HP per Turn & Satiety -5% per jam**.
