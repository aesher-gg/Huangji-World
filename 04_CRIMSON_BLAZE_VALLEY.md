# 04. Lembah Api Merah (Crimson Blaze Valley) — Huangji-World

> **Status File**: Modul Lore Wilayah (Elemen Api & Vulkanik)
> **Versi**: 3.0 (Huangji Core Edition)

---

## 🔥 1. Deskripsi Wilayah

Wilayah lautan lahar dan gunung berapi aktif. Udara dipenuhi oleh Qi elemen api yang ganas. Wilayah ini terkenal dengan industri pembuat pil (alchemy) tingkat tinggi dan kultivasi ilmu api.

---

## 📍 2. Lokasi Utama & Kota

1. **Kota Kawah Merah**: Kota yang terapung di atas danau lahar menggunakan pilar batu basal.
2. **Gua Api Purba**: Tempat persembunyian spirit beast bertema api dan herba beracun vulkanik.

---

## 🛡️ 3. Perguruan & Sekte Lokal

* **Sekte Tungku Api Merah (Crimson Furnace Sect)**: Penguasa teknik alkimia dan api pemusnah.
* **Perguruan Tinju Lava (Lava Fist Academy)**: Perguruan seni bela diri jarak dekat berbasis pukulan lahar.
