# 🔥 04. Lembah Api Merah (Crimson Blaze Valley) — Huangji-World

> **Status File**: Modul Lore Wilayah (Elemen Api & Vulkanik)
> **Versi**: 3.0 (Huangji Core Edition)
> **Spesialisasi Wilayah**: Alkimia (Alchemy), Pembuatan Pill, & Qi Api Destruktif

---

## 🏞️ I. Gambaran Umum Wilayah

Lembah Api Merah adalah rantai gunung berapi aktif dan danau lahar yang kaya akan Qi Elemen Api. Suhu udara ekstrem menjadikan wilayah ini tempat ideal bagi penyulingan pil alkimia.

* **Qi Density Modifier**: `+30% Efisiensi Alkimia & Damage Api`
* **Populasi Wilayah**: ± 32 Juta Jiwa
