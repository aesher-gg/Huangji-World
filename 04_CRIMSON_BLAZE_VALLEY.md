## 🏞️ I. Gambaran Umum Wilayah

Lembah Api Merah (*Crimson Blaze Valley*) adalah wilayah vulkanik panas di selatan Benua Huangji yang didominasi oleh gunung berapi aktif, sungai lahar mengalir, dan kawah bersuhu tinggi. Energi **Qi Elemen Api** melimpah di wilayah ini, menjadikannya pusat utama penyulingan pil alkimia tingkat tinggi dan penempaan zirah tahan panas.

| Statistik Wilayah | Nilai / Ukuran Resmi | Keterangan & Catatan |
|---|---|---|
| **Luas Wilayah Total** | ± 7,1 juta li² | Pegunungan vulkanik, sungai lahar, & kawah batu basal. |
| **Populasi Total** | ± 32 juta jiwa | Alchemist, penempa lava, & kultivator Elemen Api. |
| **Modifier Kepadatan Qi** | `+35% Efisiensi Alkimia & Damage Api, +20% Suhu Tungku` | Akselerasi pemurnian pil & serangan Hukum Api (`15`, `19`). |
| **Kapasitas Kekayaan Regional**| ± 310 Juta Tael | Soft-cap pasar komoditas pil alkimia, batu obsidian, & tembaga lahar ([`13`](https://raw.githubusercontent.com/aesher-gg/Huangji-World/main/13_ECONOMY_SYSTEM.md?v=1)). |
| **Geografi & Iklim** | Pegunungan Vulkanik, Udara Sangat Panas | Hujan abu logam, sungai lahar panas, gelombang udara kering. |

## 📜 V. Hook Misi Regional (Blaze Quest Hooks)

1. **📜 Misi 1: Panen Ginseng Lava Vulkanik (Risiko: Rendah)**
   - *Tugas*: Petik 3x *Ginseng Lava Vulkanik* di lereng kawah aktif untuk Toko Pil Magma.
   - *Syarat Akses*: Pemain Ranah Pembersihan Tubuh (Realm 1) / Pengumpulan Qi (Realm 2).
   - *Imbalan*: 20 Tael Giok Putih + 2x *Pil Vitalitas Darah* (Tier 1) + Reputasi Kota Kawah +15.

2. **📜 Misi 2: Pembasmian Perompak Red Fiend (Risiko: Sedang)**
   - *Tugas*: Tumpas Chief Red Fiend di Tebing Danau Lahar dan amankan pil alkimia jarahan.
   - *Syarat Akses*: Pemain Ranah Fondasi Jiwa (Realm 3).
   - *Imbalan*: 2 Batu Spiritual Rendah + *Golok Api Membara* (Tier 3) + Reputasi Kota Magma Baru +30.

3. **📜 Misi 3: Penambangan Tembaga Merah Lava M-4 (Risiko: Sedang)**
   - *Tugas*: Tambang 2 kantong *Tembaga Merah Lava* (M-4) dari Kawah Lahar Dalam di tengah ancaman suhu ekstrem.
   - *Syarat Akses*: Ranah Fondasi Jiwa Peak / Inti Emas.
   - *Imbalan*: 5 Batu Spiritual Rendah + 1x *Tungku Tempa Tembaga Merah* (Cauldron C-2) + 3 Tael Giok Putih.

4. **📜 Misi 4: Pemetikan Teratai Api Vulkanik Purba (Risiko: Tinggi)**
   - *Tugas*: Dapatkan 1x *Teratai Api Vulkanik Purba* (Tier 4) di dalam Jurang Lahar Neraka di tengah debuff sulfur beracun.
   - *Syarat Akses*: Ranah Inti Emas (Realm 4) atau membawa Pil Penawar Sulfur Tier 2.
   - *Imbalan*: 25 Batu Spiritual Rendah + Resep Alkimia *Pil Terobosan Nascent Soul* + Reputasi Sekte +40.
