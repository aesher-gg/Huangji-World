## 📌 Apa itu Huangji-World?

**Huangji-World Core** adalah kerangka kerja (*ruleset framework*) TTRPG/Text-RPG berbasis AI Game Master yang dirancang khusus untuk menciptakan pengalaman roleplay kultivasi Xianxia/Wuxia yang mendalam, realistis, dan **bebas dari manipulasi/kecurangan (Anti-Cheat Enforced)**.

Sistem ini memisahkan logika aturan inti, peta wilayah, hukum kultivasi, ekonomi, serta faksi ke dalam modul-modul terpisah yang saling terhubung secara otomatis via URL Raw GitHub.

---

## 🚀 Cara Memulai Permaian (Quick Start)

Untuk memulai sesi pertualangan di Benua Huangji bersama AI pilihan Anda (ChatGPT, Claude, Qwen, DeepSeek, dll.), salin (*copy*) prompt pembuka berikut dan kirimkan ke AI:

```text
Kamu adalah AI Game Master untuk RPG Xianxia "Huangji-World".
Silakan pelajari dan patuhi seluruh aturan dari link berikut sebagai sumber kebenaran utama:
https://raw.githubusercontent.com/aesher-gg/Huangji-World/main/INDEX.md

Data Karakter Baru Saya:
- Nama: [Nama Karakter Kamu]
- Wilayah Awal: [Misal: Ibu Kota Agung Huangji / Dataran Hijau Abadi / Lembah Api Merah]
- Hukum Kultivasi Awal: [Misal: Hukum Akar Kayu Suci / Hukum Inti Petir Ungu / Fana (Tanpa Hukum)]
```

## ⚖️ Prinsip Utama Huangji-World

1. **Anti-Cheat Enforced**: Tidak ada klaim statistik atau terobosan instan tanpa memenuhi formula Qi Cap, ketersediaan bahan, dan validasi AI GM.
2. **Hardcore Realism**: Kematian bersifat permanen, kelelahan dan kelaparan memengaruhi performa bertarung.
3. **Penyatuan Sistem & Lore**: Setiap faksi dan wilayah terikat pada hukum elemen dan mekanik yang konkret.
